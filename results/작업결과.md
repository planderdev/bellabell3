# 벨아벨팜 기업소개 작업 결과

갱신일: 2026년 10월 28일

## 구현 항목

기업소개 PHP 단일 페이지의 9개 섹션 순서와 지정 문구 18개를 유지했습니다. 인트로 카피의 `/`, 띄어쓰기, 문장부호와 영문 대소문자도 보존했습니다. 추가 요청에 따라 9개 섹션명 타이틀, Lorem 서브카피, 헤더와 푸터를 반영했습니다. 새로운 홍보 문장이나 아이브로우는 추가하지 않았습니다.

사용자가 추가 요청한 이미지·회색 영역·인터랙션을 다음과 같이 적용했습니다.

| 항목 | 구현 결과 |
| --- | --- |
| 섹션 타이틀 | 인트로 / 이름의 뜻 / 미션 / 연구·기술 / 사회적 가치 / 연혁 / 브랜드 패밀리 / 글로벌 / 제안 & 협업. 인트로는 H1, 나머지는 H2. |
| 서브카피 | 9개 섹션에 Lorem 본문 영역을 추가. 기존 지정 문구는 그대로 보존. |
| 헤더 | 고정 로고·6개 섹션 링크·전체 메뉴 버튼. 스크롤 시 흰 배경으로 전환. 모바일은 전체 메뉴 사용. |
| 전체 메뉴 | 9개 섹션 이동, 닫기·Escape·포커스 복귀. 모달을 연 동안 배경 스크롤 정지. 아이콘은 Lucide Equal/X. |
| 푸터 | 남색 배경, 기업 CI, 내부 링크, 지정 연락처와 Lorem 정보 영역. 미지정 회사 정보·정책·소셜 링크·저작권 문구는 생성하지 않음. |
| 이미지 | 제공 폴더의 제주 해녀, 조릿대, 봉봉이, 원물 촬영 사진 사용. 인트로는 해녀와 수산 원물 → 조릿대 순으로 구성. 외부 사이트의 사진·영상·콘텐츠는 사용하지 않음. |
| 누락 이미지 | 특허증, 업무협약, 사회적 가치 증빙, 연혁 대표 사진, 아우아우, 해외 박람회 사진의 기본 6개 영역을 회색 처리. 상태 문구·이미지 아이콘은 없음. |
| 인트로 | 여백 있는 이미지 프레임이 전체 화면으로 확대되고, 로고·카피가 순서대로 등장. |
| 사진 슬라이드 | Swiper 페이드, 드래그, 자동 전환. 봉봉이 사진도 실제 제공 사진으로 구성. |
| 부드러운 스크롤 | Lenis와 GSAP ScrollTrigger의 프레임 갱신을 동기화. |
| 이름의 뜻 | PC에서 다이아몬드 마스크 이미지가 전체 화면으로 확장되는 핀스크롤. 모바일은 일반 세로 배치. |
| 미션 | 사진이 가로로 드러나는 스크롤 효과와 사진 슬라이드. 구조 이야기 원문은 확인되지 않아 공란 유지. |
| 연구·기술 | 회색 문서 이미지 영역이 가로로 이동하는 핀스크롤. |
| 사회적 가치 | 지정된 다섯 짧은 항목에 AOS 등장 효과. 증빙 이미지 영역은 회색. 서브카피 자리에 Lorem만 사용. |
| 연혁 | 후보 11건은 비공개 데이터로 유지. 공개 확정 연도·내용은 없으며, 이미지 영역만 회색. |
| 브랜드 패밀리 | 이미지 축소와 카드 등장 핀스크롤, 카드 선택, 모바일 스와이프. 아우아우 선택 시 해당 이미지도 회색. 이동 URL은 추가하지 않음. |
| 글로벌 | 전체 회색 이미지가 썸네일로 축소되고 파란 배경으로 전환되는 핀스크롤. 확정되지 않은 실적 문구·지도·국기·카운터는 없음. |
| 문의 | 지정 제목·연락처 유지. 입력 필드·전송 명세가 없어 폼과 API는 생성하지 않음. 연락처 표시를 수신 설정으로 사용하지 않음. |

## 검수

- 자동 점검 **102/102 통과**: [checks.json](checks.json). 지정 문구 18개, 타이틀 9개, Lorem 9곳, 실제 이동 대상과 일치하는 링크를 대조했습니다.
- 375 / 390 / 768 / 1024 / 1440px에서 가로 넘침·문구 잘림·깨진 이미지 없음: [responsive.json](responsive.json).
- PC 4개, 모바일·태블릿 3개 핀 구간이 실제 생성되는 것을 확인했습니다.
- 브라우저에서 마우스 드래그 전후의 활성 사진이 변경되는 것을 확인했습니다.
- 이름의 뜻 구간에서 세로 위치가 고정된 상태로 이미지 마스크가 확장됨을 확인했습니다.
- 가로 핀 구간에서 고정 위치를 유지하면서 가로 이동 값이 변하는 것을 확인했습니다.
- AOS 대상 다섯 항목의 등장 상태와 브랜드 카드 선택 상태를 확인했습니다.
- 글로벌 구간에서 회색 이미지 폭이 축소되고 파란 배경이 표시되는 것을 확인했습니다.
- 위 동작 증빙: [interactions.json](interactions.json).
- PHP 및 JavaScript 구문 점검 통과. 브라우저 콘솔 오류 없음.
- 화면 크기·동작 줄이기 설정 변경 시 남은 애니메이션이 계속 실행되지 않도록 정리 코드를 적용했습니다.
- 모바일에서 PC로 너비가 바뀔 때 새 너비를 먼저 반영하여 연구 구간의 가로 핀이 누락되지 않도록 수정했습니다.
- 타이틀·서브카피가 이미지와 함께 움직이도록 기존 핀 애니메이션을 연결했습니다.
- 전체 메뉴 열기·링크 선택 후 닫기·Escape·포커스 복귀와 모달 중 배경 스크롤 정지를 브라우저에서 확인했습니다.
- 모바일 글로벌 구간에서 타이틀과 Lorem이 화면 안에 표시됨을 확인했습니다. 헤더 높이는 모바일 70px, 태블릿 80px, PC 100px입니다.

## 계속 비워둔 내용

해녀·조릿대 영상 원본, 봉봉이 구조 이야기 원문, 대표 특허증과 등록 정보, 제주대학교 협약 문서·사진·설명 원문, 연혁 최종 채택, 아우아우 사진·로고·이동 주소, 확정된 글로벌 실적 문구·박람회 사진, 문의 필드·버튼·동의문·전송 API·수신 설정은 여전히 확인되지 않았습니다.

이미지는 회색으로 표시하고, 추가 요청한 서브카피 자리에는 Lorem을 사용했습니다. Lorem은 확정 원문이나 실적을 대신하는 정보가 아닙니다. 연혁·실적·폼은 추측해서 채우지 않았습니다.

- 프로젝트 루트 `README.md`: 실행 방법.
